# Code of Conduct

## Our Pledge

We are committed to making participation in this project a respectful, constructive, and harassment-free experience for everyone.

## Expected Behavior

- Be respectful and precise.
- Assume good faith while discussing technical disagreements.
- Accept constructive criticism.
- Focus on the issue, evidence, and impact.
- Protect private data and do not publish user media or credentials.

## Unacceptable Behavior

Harassment, discrimination, personal attacks, doxxing, threats, deliberate disclosure of private information, and disruptive bad-faith behavior are not acceptable.

## Enforcement

Report unacceptable behavior privately to the repository maintainers through GitHub. Reports will be reviewed and handled proportionately, with privacy respected where practical.

This code of conduct is adapted from the Contributor Covenant, version 2.1.
